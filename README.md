## О проекте

Приложение берёт таблицу с результатами нескольких исследований (среднее значение и доверительный интервал по каждому) и строит forest plot — стандартный график для мета-анализа, применяемый в медицинских и научных публикациях.

Рассчитан на пользователя без опыта программирования: загрузка файла, редактирование данных и сохранение результата — в несколько кликов.

---

## Возможности

- Загрузка данных из `.xlsx`, `.xls` и `.csv`
- Редактируемая таблица предпросмотра — двойной клик по ячейке
- Fixed-effect и random-effects (DerSimonian–Laird) модели пулинга
- Расчёт гетерогенности: I², Cochran's Q, p-value, τ²
- Числовые колонки рядом с графиком (N, среднее с 95% ДИ, вес исследования)
- Предупреждения о пропущенных данных, дублях исследований и статистических выбросах
- Шрифт графика — Times New Roman 14 pt
- Переключатель показа строки «Итого» на графике
- Экспорт графика в PNG/PDF и таблицы расчётов в CSV

---

## Формат входных данных

Таблица должна содержать четыре колонки:

| Название исследования | К-во объектов в исследовании | Среднее | Ширина 95% доверительного интервала |
| ---------------------- | ----------------------------- | ------- | ------------------------------------ |
| Майер, 2000             | 15                             | 57      | 5                                     |
| Петров, 2025            | 30                             | 59      | 9                                     |
| Сахил, 2022             | 25                             | 61      | 11                                    |

Пример файла — `Пример данных для forest plot.xlsx` в корне репозитория.

## Статистика

- **Fixed-effect**: веса по инверсной дисперсии (`1 / SE²`)
- **Random-effects**: DerSimonian–Laird, `τ² = max(0, (Q - df) / C)`
- **I²**: доля вариации между исследованиями, не объяснимая случайностью выборки
